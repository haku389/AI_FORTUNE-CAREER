## 1. サービス概要

**「転職するか迷っているすべての人」に向けた、占い×転職診断のWebサービス。**

誕生日・出生時刻・MBTI・転職に関する質問への回答から、星座占い（西洋占星術）・九星気学・MBTIを組み合わせて「転職タイミング」「転職スコア」「向いている業界・職種」を診断し、占い師ペルソナ「白石玲子」の語り口でパーソナライズされた鑑定文を届ける。診断結果から転職エージェント・転職サイトへのアフィリエイト送客を行うのが収益モデル。

- 運営者キャラクター: **白石玲子（キャリア未来鑑定士）** — 詳細は[6章](#6-キャラクターペルソナ-白石玲子)
- リポジトリ内呼称: `career-uranai`
- 主要言語: 日本語のみ（多言語対応なし）

## 3. 診断コンテンツの詳細

### 3.1 無料・簡易診断（`/shindan/form`）

- **質問数**: 5問（1問1画面、誕生日入力含む）
- **利用制限**: 1日1回・毎日0時にリセット
- **入力項目**: ニックネーム、誕生日、性別
- **質問テーマ**（惑星をモチーフにした5ブロック）:
  1. 🪐 土星 — 今の職場への限界感
  2. 🌟 木星 — 仕事で大切にしたいもの（年収/環境/やりがい/安定の4タイプ判定）
  3. 🌑 月 — 深夜に浮かぶ本音（ストレスタイプ判定）
  4. ⛈️ 土星 — 日曜の夜の憂鬱度
  5. 🌌 木星 — 5年後の職場想像
- **結果に表示される内容**:
  - 転職スコア（50〜92点、回答から算出した`urgency`値を正規化）
  - 転職タイミング判定: `now`（今すぐ）/`3m`（3ヶ月以内）/`6m`（半年後）/`wait`（充電期）
  - 転職タイプ判定: `career`（キャリアアップ型）/`env`（環境改善型）/`calling`（天職探し型）/`stable`（安定志向型）
  - 「月の声」（ストレスタイプ別の固定メッセージ）
  - 「土星の試練」（日曜夜の憂鬱度タイプ別の固定メッセージ）
  - 白石玲子からのメッセージ（AIが診断結果をもとに生成する200〜280字の鑑定文）
  - おすすめ転職エージェント（タイプ別に1〜2件、アフィリエイトリンク）
  - 結果をX/LINEなどにシェアできるOGP画像付きシェア機能
  - 精密診断への誘導CTA

### 3.2 精密診断（`/premium/form`）

- **利用条件**: **LINEログイン必須**（個人情報取得・後日のLINE配信のため。決済は現状発生しない）
- **質問数**: 25問・6ブロック構成（土星・水星・金星・火星・木星・月・冥王星など10天体をモチーフにした多軸質問。複数選択可の質問あり）
  1. 土星が刻む「今の場所と時間」（4問）— 限界感の深さ、転職経験・在籍年数
  2. 惑星が読み解く「魂の色」（6問）— MBTI、モチベーション源、ストレス反応、理想の上司像、コミュニケーション型、意思決定スタイル
  3. 木星が照らす「次の場所」（8問）— 現職業界、希望業界、希望する役割、希望勤務エリア・都道府県、独立志向、年収重視度、転職への障壁
  4. 月が守る「魂の居場所」（4問）— 働き方の好み、希望組織規模、ワークライフバランスの優先事項、5年後のビジョン
  5. 星が映す「隠れた自分」（3問）— 自己評価する市場価値、他者からの評価、転職活動の最初の一手
  6. 冥王星が問う「最後の扉」（1問）— 変容への覚悟（総括質問）
- **追加入力項目**: 出生時刻（任意、精度向上のため）、MBTI（わからない場合は4タイプ群から選択可）
- **診断ロジック**: 太陽星座・月星座・本命星（九星気学）・MBTIの**4軸**を掛け合わせて算出
- **結果ページの構成（6セクション）**:
  1. 星のプロフィール（太陽星座・月星座・本命星・MBTIのサマリー）
  2. 転職スコア詳細（スコア・タイミング・根拠）
  3. 向いている職種・業界TOP（14職種からスコアリングしてマッチング、職種ごとに40〜60字のコメント付き）
  4. 今後3ヶ月の行動アドバイス（AIがJSON形式で月ごとの行動指針を生成）
  5. 白石玲子の鑑定メッセージ（AIが生成する2,000〜2,800字の精密鑑定文）
  6. おすすめ転職エージェント（業界別に2〜4件）
- **結果の永続化**: Supabaseに保存され、`/premium/result/[id]` の固有URLで後から閲覧可能。LINEで結果リンクを配信。

### 3.3 占い図鑑（`/guide`配下）

転職診断で使用する3占術（西洋占星術・九星気学・MBTI）の解説記事群。SEO流入と、診断結果の「説得力」「裏付け」を補強する役割。MBTIは16タイプ別に個別ページを生成（`generateStaticParams`によるSSG）。

## 4. 診断ロジックの裏側（要点）

- **転職スコア**: 各質問の回答に重み付けされた`urgency`（緊急度）の合計を正規化して算出。簡易診断は50〜92点、精密診断は50〜97点（精密の方が上限が高く、差別化されている）。
- **転職タイミング**: `urgency`の合計値によって `now` / `3m` / `6m` / `wait` の4段階に分類。
- **転職タイプ**: `career`（キャリアアップ）/ `env`（環境改善）/ `calling`（天職探し）/ `stable`（安定志向）の4分類で、おすすめ転職エージェントの出し分けに使用。
- **職種マッチング**（精密診断）: 役割タグ・MBTI・モチベーション・太陽星座/月星座/本命星のボーナス値を加算するスコアリングモデルで14職種から上位を算出。
- すべての鑑定文・コメントは「白石玲子の声」として一貫した口調（後述）で生成・表示される。

## 5. マネタイズ・送客導線

- **アフィリエイト送客が主収益源**。転職タイプ・希望業界・職種マッチングに応じて、BIZREACH／doda／マイナビ転職／Green／レバテックキャリア／JACリクルートメント／ハタラクティブ等の転職サイト・エージェントを出し分けて紹介し、白石玲子のコメント付きでリンクを表示。
- **Stripe決済（¥1,980）の実装は存在するがフロントエンドから呼ばれておらず未稼働**。現状、精密診断は「LINEログイン」のみがゲートで、金銭的な課金フローはない（将来的な有料化を見越した実装と推測される）。
- **LINE連携**は個人情報取得とリテンション（鑑定結果の配信、再訪導線）が目的。

## 7. ターゲットユーザー像

### コア・デモグラフィック
**28〜38歳の女性**（AIプロンプト内でも明示的にターゲット定義されている層）。新卒〜中堅でキャリアを積み、転職を意識し始めるが「今動くべきか」を一人で判断しきれずにいる層。

### ペルソナ例

**ペルソナA：「迷えるキャリアウーマン」鈴木さん（32歳・女性）**
- IT企業の営業職、社会人歴9年、転職経験1回
- 仕事に大きな不満はないが、「このままでいいのか」という漠然とした焦りを日曜の夜に感じる
- 年収より「やりがい」を重視したいが、踏み出す決め手がない
- 占いやMBTI診断が好きで、Instagramで星座占いをよくシェアする
- → **簡易診断の主要利用者像**。1日1回の無料診断を友人とシェアしながら楽しみ、結果に納得感があれば精密診断・転職エージェントへ流れる

**ペルソナB：「本気で動きたい」佐藤さん（35歳・女性）**
- メーカー企画職、管理職一歩手前、転職回数0回
- 職場の人間関係・評価制度に強いストレスを抱え、「もう限界かも」と感じ始めている
- 自分の市場価値に自信が持てず、一人で転職活動を始めるのが怖い
- LINEで情報を受け取る習慣があり、じっくり読める診断結果を求めている
- → **精密診断（LINEログイン経由）の主要利用者像**。出生時刻やMBTIまで入力する手間を惜しまず、深い自己理解とエージェント紹介までを一気通貫で求める

**ペルソナC：「占いついでに転職情報も」高橋さん（29歳・女性）**
- 接客・サービス業、転職は未経験だが将来に漠然とした不安
- 星座占い・タロットなどのエンタメ消費として診断を受ける
- 転職の本気度は低いが、エージェント紹介をきっかけに情報収集を始める可能性がある
- → **アフィリエイト送客のロングテール層**。診断の「当たってる感」と白石玲子のキャラクター性がエンタメ的に刺さる

### 刺さる理由（共通項）
- 「転職占い」という入り口の軽さ・エンタメ性で心理的ハードルを下げつつ、MBTI・出生時刻まで使う精密診断で「ちゃんとした自己分析」としての説得力も両立している
- 一人で転職を決断するのが怖い・誰にも相談できない、という孤独感に「白石玲子」という伴走者キャラクターが寄り添う設計
- 占い好き層とキャリア意識層が重なる20代後半〜30代後半の女性に対し、SNSシェア（OGP画像）を前提とした設計でバイラルしやすい

## 8. 技術スタック概要

- **フレームワーク**: Next.js（App Router, Turbopack）
- **AI生成**: Anthropic Claude API（`@anthropic-ai/sdk`）— 鑑定文・3ヶ月アドバイスの生成
- **DB**: Supabase（精密診断結果の永続化）
- **決済**: Stripe（実装済みだが未稼働）
- **認証/配信**: LINEログイン・LINE Messaging API
- **画像生成**: `next/og`（OGPシェア画像の動的生成）
- **解析**: Google Analytics（GA_ID）
